# X68000 Compact external SCSI adapters

Two alternative boards that bring the external half-pitch (MDR 50) SCSI port of the X68000 Compact out to a standard 2x25, 2.54 mm SCSI header. Both follow the half-pitch pinout of the X68000 Book, Appendix D.10. Use one or the other; each folder has its own README with usage instructions, pin table and revision notes.

- [`MDR-50_Male-Male`](MDR-50_Male-Male/README.md) - half-pitch connector on the board.
- [`SCSI-CN50-28AWG`](SCSI-CN50-28AWG/README.md) - solder pads for the wires of a half-pitch plug cable.

Not yet tested on real hardware: check every link with a meter before use. Do not use the Rev 1.0 MDR-50 boards.
